# Termux API Skill

Panduan penggunaan perintah `termux-api` di lingkungan Termux Android untuk berinteraksi dengan sensor dan fitur sistem Android.

## Perintah Penting
- `termux-battery-status`: Memeriksa persentase baterai, kesehatan, suhu, dan status pengisian daya.
- `termux-toast <pesan>`: Menampilkan notifikasi popup toast instan di layar.
- `termux-vibrate -d <ms>`: Menggetarkan perangkat selama durasi milidetik tertentu.
- `termux-clipboard-get`: Mengambil isi teks dari clipboard Android.
- `termux-clipboard-set <teks>`: Menyalin teks ke clipboard Android.
- `termux-notification --title <judul> --content <isi>`: Mengirim notifikasi bilah status Android.
