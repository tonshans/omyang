# Script Utilities Documentation

Dokumentasi penggunaan skrip utilitas bawaan yang tersedia di direktori `./scripts/`.

## 1. System Check (`./scripts/system_check.sh`)
Menampilkan ringkasan informasi kernel, ruang disk, dan memori sistem.
Penggunaan:
```bash
bash ./scripts/system_check.sh
```

## 2. Network Test (`./scripts/network_test.sh`)
Menguji konektivitas internet dengan mengirim ping ke DNS resolver publik.
Penggunaan:
```bash
bash ./scripts/network_test.sh
```
